# Project continuity

Read [HANDOFF.md](HANDOFF.md) when starting work in this project. It records the user's requirements, project history, architecture, compatibility decisions, previous verification, and known limitations through 2026-11-12.

Treat the handoff as a dated snapshot, not a replacement for the current user's instructions or the actual code. Check the current Git state before editing and preserve unrelated changes in the parent Learning-Repo repository. Consult [docs/development.md](docs/development.md) for development and validation commands.

Update the handoff after substantial changes so later sessions can continue from the actual state. Do not copy credentials, tokens, or the contents of `auth/.env` into documentation.
