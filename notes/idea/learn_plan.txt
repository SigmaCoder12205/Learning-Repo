All small stuff need to know E for early and L for later

Tooling and workflow
(E) Git branching, commit habits and tags
(E) CMake, plus a package manager (vcpkg or Conan)
(E) A real debugger (gdb/lldb or Visual Studio) and breakpoints, watchpoints and core dumps
(E) Compiler warnings (-Wall -Wextra) and sanitizers (ASan, UBSan, TSan)
(E) Unit testing (GoogleTest or Catch2)
(E) clang-format and clang-tidy
(L) Profiling (perf, VTune or Tracy) and Valgrind
(L) CI (GitHub Actions) that builds and tests every push
(L) Logging (spdlog) and assertions
C++ beyond the basics
(E) RAII, smart pointers, move semantics, rule of 0/3/5
(E) STL containers and algorithms (and when each is slow)
(E) Undefined behavior: what it is and the common ways to trigger it
(E) Templates, lambdas, constexpr, C++20 concepts
(L) Atomics and the memory model (acquire/release ordering)
(L) CPU cache behavior, false sharing, alignment
(L) Custom allocators (arena and pool)
(L) Error handling strategy (exceptions vs std::expected)
(L) Endianness and struct packing (matters for networking)
Simulation design
(E) Fixed-timestep, deterministic simulation loops
(E) ECS patterns
(E) Seeded pseudo-random number generators, so runs are reproducible
(L) Floating-point determinism (it can differ across machines and compilers; fixed-point is sometimes the fix)
(L) Event and message systems
(L) Save/load and replay systems (replays come almost free if the sim is deterministic)
(L) Config and data-driven design (JSON/TOML for balance numbers, so you don’t recompile to tweak)
Math and algorithms
(E) Big-O, core data structures, graph theory (your map is a graph)
(E) Probability and statistics (combat resolution, balance)
(L) Pathfinding (A*, Dijkstra) for army movement
(L) Spatial structures (quadtrees, spatial hashing)
(L) Linear algebra, quaternions, geometry, map projections
(L) Game theory and basic economics modeling (for the realism you want)
Networking
(L) Sockets (Berkeley sockets or Asio), TCP vs UDP
(L) Latency, jitter and packet loss, and how to simulate them for testing
(L) Binary serialization (Protobuf or FlatBuffers)
(L) Snapshot and delta compression, interest management (only send players what’s relevant, essential for 1000 players)
(L) Lag compensation and interpolation
(L) NAT traversal or relay servers
(L) TLS/authentication, input validation, DoS basics
SQL and backend
(L) SQLite first, then PostgreSQL
(L) Transactions and ACID
(L) Prepared statements (SQL injection)
(L) Schema migrations
(L) Connection pooling and backups
(L) Linux basics, Docker, systemd and monitoring for hosting the server
Graphics and Blender
(L) Shaders (GLSL), cameras, culling, instancing
(L) Dear ImGui for debug and UI tooling
(L) Text rendering and texture formats
(L) Blender: UV unwrapping, normals, LODs, naming conventions, export settings
Data and research
(L) Sourcing real country data (GeoJSON borders, economic and military datasets) and checking its licenses
(L) Reading docs, standards and papers (cppreference, RFCs, game AI papers)
Habits
(E) Write the design doc before major systems
(E) Profile before optimizing
(E) Keep a decisions log: “I chose X over Y because Z”
