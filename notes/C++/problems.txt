Your program enters an infinite loop when non-numeric input is entered because of two issues with how
input errors and stream buffering are handled in C++:

std::cin.clear() only resets flags: When you enter a letter for an integer variable (choice),
std::cin enters a fail state and stops reading.
Calling std::cin.clear() clears the error flag so cin can be used again, but it leaves the unread text sitting in the input buffer.

fflush(stdin) is undefined behavior: In standard C++, fflush() is designed only for output streams (like stdout).
 Using it on stdin does not reliably flush or clear the input buffer across different compilers.

On every subsequent loop iteration, std::cin >> choice attempts to read the same leftover letters again, fails immediately,
prints the menu, and loops endlessly.

How to Fix It: Replace fflush(stdin) with std::cin.ignore(),
               which explicitly discards characters currently in the input stream up to the next newline character ('\n').
