Strings 
    
    1. Length or size: strName.length() or strName.size()
    
    2. Check if empty: strName.empty()
    
    3. measures character capacity: strName.capacity()
    
    4. Resevre memory space for a string: strName.reserve()
    
    5. Concatenation: strName + strName2 or strName.append(strName2)

    6. Get a character at an index: strName.at(index)

    7. Extract a part into a new string: strName(startIndex, length)

    8. Find a part of the string: strName.find(target)                 // Returns starting index or 18446744073709551615 if no matching cases found

    9. Acess a character at an index: strName[index]

    10. Get the first character: strName.front()

    11. Get the last character: strName.back()

    12. Clear the string: strName.clear()

    13. Push a Character to end of a string: strName.push_back(character)

    14. Remove the last character of a string: strName.pop_back() 

    15. Insert a specific string into an index: strName.insert(index, strName2)

    16. Earse a section of a string: strName.earse(index, length)

    17. Find the last occurrence of a string in a string: strName.rfind(target)
