What is a port?

Ports are numerical endpoints (0 to 65535) that allow a computer to run multiple applications and services over a single 
network connection. It uses can use 2 protocols to transport data, TCP (Transmisson Control Protocol) which garentees data delivery
and there's UDP (User Datagram Protocol) which prioritizes speed over delivery checks.

The Internet Assigned Numbers Authority (IANA) divides all 65535 ports into 3 catorgories 

Well-Known Ports (0 to 1023) these are reserved for core system ultities and stuff like web browsing and email, usally name root power to run
Registered Ports (1024 to 49151) assigned to software, applications, databases and third party vendors (Like Microsoft, MySQL or game servers)
Dynamic/Ephemeral Ports (49152 to 65535) Temporay ports used on the fly by client devices for example when you open your laptop the web and it needs to talk to a web sever it would use thiw

What is a TCP?

TCP stands for Transmisson Control Protocol, and it is the fundamental set of rules for a computer to communicate 
reliably over the internet. If the Internet Protocol (IP) is like a mailing system then TCP is the person who stands 
at the door checking every note and message that comes through to the IP then puts them in correct orders and asks 
the sender to remall any lost messages.

TCP is connection-orientated protocol. Before any computer can send data to a sever (Like loading a website) they must 
perform a digital handshake to make a connection. 

The hand shake:

Step 1 SYN (Synchronize): The client asks can we open a connection
Step 2 SYN-ACK (Synchronize-Acknowledge): The sever replies yes I am ready what about you
Step 2 ACK (Acknowledge): Then the client says yes then all the data starts flowing through

Unlike UDP, TCP prefers accuracy over speed, TCP splits data files into small chuncks called segments. It numbers each 
segment and if the segment arrives out of order maybe to a delay or something, it resends the file. The reciving device 
must tell the sender when it got each segment if a segment get's lost the reciver tells the sender then the sender waits a 
moment then resends the segment. TCP is smart enough to manage network traffic, if a powerful server sends data too fast 
TCP can slow it down, so data doesn't pile up and crash. 

What is a socket and what does it do?

A socket let's two programs pass data back and forth over a network.

Differences 

IP: Is like a home address (It gets data to the right computer)
Port: The apartment number (It get's you the right service)
Socket: The physical door to the apartment (It is the actual open channel where the conversation takes place)

A socket cotains in a tuple the TCP + IP + The Port Number

A socket is manages the raw complex infrastructures of network cards, routers and data streams so the regular 
software application doesn't have to. It's main responabilty's are 

Establishing a connections, Managing the data buffer and differenating multiple connections

What does it mean for a port to be open closed or unreachable?

1. Open
    An open port means the port is reachable and an active application is running listening on that port for data 

2. Closed
    A closed port means the port is reachable but no app is listening on it for data 

3.Unreachable
    An unreachable port means you cannot determine weather the port is open or closed because something is blocking 
    the communication line.
